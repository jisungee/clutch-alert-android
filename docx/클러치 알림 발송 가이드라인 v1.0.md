# **⚾ 클러치 알림 발송 가이드라인 v1.0**

## **1. 기본 원칙**

클러치 알림은 사용자가 선호하는 팀의 경기 상황을 실시간으로 전달하는 서비스다.

알림은 다음 세 가지 원칙을 따른다.

1.  **명확성:** 누가 무엇을 했고 어떤 결과가 발생했는지 전달한다.

2.  **즉시성:** 경기 상황이 확정되면 가능한 한 빠르게 발송한다.

3.  **중복 방지:** 하나의 플레이에서 여러 알림 조건이 발생하면 중요한 알림을 우선한다.

모든 알림은 사용자가 선택한 선호 팀을 기준으로 작성한다.

## **2. 알림별 발송 기준**

| **알림 종류**  | **발송 조건**                                 | **발송 시점**      |
|----------------|-----------------------------------------------|--------------------|
| ⚾ 경기 시작   | 첫 투구로 경기가 시작됨                       | 첫 투구 이후       |
| ⚾ 공격 시작   | 선호 팀의 공격 이닝 시작                      | 공격 시작 시       |
| ⚾ 공격 종료   | 선호 팀 공격에서 3아웃 발생                   | 3아웃 확정 시      |
| 🛡️ 수비 시작   | 선호 팀의 수비 이닝 시작                      | 수비 시작 시       |
| 🛡️ 수비 종료   | 상대 팀 공격에서 3아웃 발생                   | 3아웃 확정 시      |
| 🏃 출루        | 선호 팀 타자가 출루에 성공                    | 출루 확정 시       |
| 🎉 득점        | 선호 팀의 점수 증가                           | 득점 확정 시       |
| 🔥 동점        | 선호 팀의 득점으로 동점 달성                  | 점수 변경 시       |
| 🚨 역전        | 지고 있던 선호 팀이 앞서게 됨                 | 점수 변경 시       |
| 💥 홈런        | 선호 팀 타자의 홈런 발생                      | 홈런 확정 시       |
| ⚠️ 실점        | 상대 팀의 점수 증가                           | 실점 확정 시       |
| 📺 비디오 판독 | 공식 비디오 판독 시작                         | 판독 시작 시       |
| 🚑 부상        | 선수의 부상 의심으로 경기 중단 또는 치료 진행 | 상황 확인 시       |
| 🔥 빅이닝      | 한 팀이 같은 공격 이닝에서 4득점 이상 기록    | 4번째 득점 확정 시 |

※ 빅이닝은 클러치 자체 기준으로 4득점 이상을 사용한다.

## **3. 출루 알림 세부 기준**

출루 알림은 선호 팀의 타자가 베이스에 살아 나갔을 때 발송한다.

### **3-1. 출루 유형**

| **상황**              | **발송 여부** | **알림 예시**                      |
|-----------------------|---------------|------------------------------------|
| 1루타                 | ✅            | 🏃 삼성 구자욱 안타! 1루 출루      |
| 2루타                 | ✅            | 🏃 삼성 구자욱 2루타! 득점권 진입  |
| 3루타                 | ✅            | 🔥 삼성 구자욱 3루타! 득점 찬스    |
| 볼넷                  | ✅            | 🏃 삼성 구자욱 볼넷으로 출루       |
| 몸에 맞는 공          | ✅            | 🏃 삼성 구자욱 사구로 출루         |
| 실책 출루             | ✅            | 🏃 삼성 구자욱 상대 실책으로 출루  |
| 낫아웃 출루           | ✅            | 🏃 삼성 구자욱 낫아웃으로 출루     |
| 도루                  | ❌            | 기존 주자의 진루이므로 출루가 아님 |
| 폭투로 기존 주자 진루 | ❌            | 새로운 타자의 출루가 아님          |
| 홈런                  | 💥            | 홈런 알림으로 처리                 |

※ 야수선택으로 타자가 살아 나간 경우도 출루 상황으로 처리한다.

### **3-2. 출루 후 주자 상황**

출루 알림에는 출루 결과와 함께 현재 주자 상황을 표시한다.

| **주자 상황** | **알림 예시**                   |
|---------------|---------------------------------|
| 1루           | 🏃 삼성 구자욱 안타! 주자 1루   |
| 2루           | 🔥 삼성 구자욱 2루타! 득점 찬스 |
| 1·2루         | 🔥 삼성 구자욱 안타! 1·2루 찬스 |
| 1·3루         | 🔥 삼성 구자욱 안타! 1·3루 찬스 |
| 2·3루         | 🔥 삼성 구자욱 안타! 2·3루 찬스 |
| 만루          | 🚨 삼성 구자욱 볼넷! 만루 찬스  |

아웃카운트도 함께 표시한다.

**예시**

- 0아웃 → 무사

- 1아웃 → 1사

- 2아웃 → 2사

알림: 🔥 삼성 구자욱 안타! 2사 1·2루 찬스

### **3-3. 득점권 판단 기준**

2루 또는 3루에 주자가 있다면 득점권 상황으로 분류한다.

다만 이미 득점권에 주자가 있는 상황에서 새로운 타자가 출루하면 출루 알림에 현재 주자 상황을 포함해 전달한다.

## **4. 득점 및 실점 세부 기준**

득점 알림은 단순 득점, 동점, 역전을 구분한다.

### **4-1. 득점 유형**

| **득점 상황** | **알림 예시**                       |
|---------------|-------------------------------------|
| 일반 득점     | 🎉 삼성 김OO 적시타! 1점 득점, 3:2  |
| 동점          | 🔥 삼성 김OO 적시타! 3:3 동점       |
| 역전          | 🚨 삼성 김OO 2타점 적시타! 4:3 역전 |
| 솔로 홈런     | 💥 삼성 김OO 솔로 홈런! 5:3         |
| 2점 홈런      | 💥 삼성 김OO 2점 홈런! 5:3          |
| 역전 홈런     | 🚨 삼성 김OO 역전 3점 홈런! 5:3     |
| 끝내기 안타   | 🎉 삼성 김OO 끝내기 안타! 5:4 승리  |

**동점 판단 기준**

- 득점 이전에는 상대 팀보다 점수가 낮음

- 득점 이후 양 팀의 점수가 같아짐

**역전 판단 기준**

- 득점 이전에는 상대 팀보다 점수가 낮음

- 득점 이후 상대 팀보다 점수가 높아짐

동점에서 앞서기 시작한 경우는 역전이 아닌 리드 상황으로 구분한다.

### **4-2. 실점 유형**

| **상황**  | **알림 예시**                        |
|-----------|--------------------------------------|
| 일반 실점 | ⚠️ 삼성 1실점 허용! 현재 3:2         |
| 동점 허용 | ⚠️ 롯데 김OO 적시타! 3:3 동점        |
| 역전 허용 | 🚨 롯데 김OO 2점 홈런! 3:4 역전 허용 |

※ 점수는 항상 선호 팀 : 상대 팀 순서로 표기한다.

## **5. 비디오 판독 알림 기준**

비디오 판독은 정식 판독이 시작되었을 때 발송한다.

| **상황**  | **알림 예시**                         |
|-----------|---------------------------------------|
| 판독 시작 | 📺 3회초, 1루 세이프 여부 비디오 판독 |
| 원심 유지 | 📺 비디오 판독 결과, 원심 유지        |
| 판정 번복 | 📺 비디오 판독 결과, 세이프로 번복    |

단순 중계 리플레이는 비디오 판독으로 취급하지 않는다.

## **6. 부상 알림 기준**

부상 알림은 확인된 상황만 전달한다.

| **상황**    | **알림 예시**                        |
|-------------|--------------------------------------|
| 부상 의심   | 🚑 삼성 김OO 부상 의심, 경기 중단    |
| 의료진 확인 | 🚑 삼성 김OO 부상으로 의료진 확인 중 |
| 부상 교체   | 🚑 삼성 김OO 부상으로 교체           |

부상 여부가 확정되지 않았다면 '부상 의심'으로 표현한다.

## **7. 빅이닝 알림 기준**

클러치에서는 **한 팀이 한 번의 공격 이닝에서 4점 이상 득점한 경우**를 빅이닝으로 정의한다.

### **발송 조건**

- 같은 공격 이닝에서 누적 4득점 이상

- 4번째 득점이 확정된 시점에 발송

- 동일 팀의 동일 공격 이닝에서는 1회만 발송

**예시**

5회초 삼성의 득점 상황

- 첫 번째 득점: 1점

- 두 번째 득점: 2점 추가 (누적 3점)

- 세 번째 득점: 1점 추가 (누적 4점)

🔔 알림

🔥 삼성 5회초 4득점! 빅이닝 달성!

## **8. 중복 알림 방지 규칙**

하나의 플레이에서 여러 조건이 발생하더라도 기본적으로 하나의 알림만 발송한다.

### **예시 ① 역전 홈런**

상황: 삼성 선수가 2점 홈런을 쳐서 역전

발생 조건

- 출루

- 득점

- 역전

- 홈런

**최종 발송**

🚨 삼성 김OO 역전 2점 홈런! 4:3

### **예시 ② 적시타로 빅이닝 달성**

상황: 5회초 적시타로 삼성의 해당 이닝 누적 득점이 4점이 됨

발생 조건

- 출루

- 득점

- 빅이닝

**최종 발송**

🔥 삼성 김OO 적시타! 5회초 4득점 빅이닝

### **예시 ③ 이닝 교대**

상황: 3회초 삼성 공격에서 3아웃 발생

발생 조건

- 삼성 공격 종료

- 삼성 수비 시작 예정

**최종 발송**

⚾ 삼성 3회초 공격 종료! 수비 전환

수비 시작을 별도로 알리지 않아도 되는 경우에는 중복 발송하지 않는다.

## **9. 알림 우선순위**

여러 조건이 동시에 발생하면 가장 중요한 상황을 중심으로 알림을 구성한다.

| **우선순위** | **상황**       | **처리 방법**              |
|--------------|----------------|----------------------------|
| 1            | 끝내기·역전    | 최우선 발송                |
| 2            | 홈런           | 홈런 종류와 득점 결과 표시 |
| 3            | 동점·득점·실점 | 변경된 점수 표시           |
| 4            | 빅이닝         | 이닝 누적 득점 표시        |
| 5            | 출루           | 출루 선수와 주자 상황 표시 |
| 6            | 이닝 전환      | 공수교대 상황 표시         |

비디오 판독과 부상은 경기 흐름의 별도 이벤트로 관리한다.

**중요:** 우선순위가 낮다는 이유로 모든 출루나 빅이닝 알림을 생략하는 것이 아니라, 동일한 플레이에서 더 중요한 상황이 함께 발생한 경우에만 통합한다.

## **10. 공통 알림 작성 형식**

가능한 한 다음 형식을 사용한다.

**\[아이콘\] \[팀명\] \[선수명\] \[발생 상황\]! \[경기 결과\]**

예시

- 🏃 삼성 김OO 안타! 2사 1·2루 찬스

- 💥 삼성 김OO 2점 홈런! 5:3

- 🚨 삼성 김OO 역전 적시타! 4:3

- ⚠️ 롯데 김OO 적시타! 삼성 2실점

선수명이 필요한 알림에는 선수명을 포함하고, 이닝 알림처럼 선수와 무관한 상황에서는 팀명과 이닝만 사용한다.
