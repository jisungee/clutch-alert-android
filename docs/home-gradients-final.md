# 10개 구단 홈 그라데이션 확정 적용

2026-11-24. 사용자가 확정한 한화·삼성·KIA·KT 디자인을 보존하고 나머지 6개 구단을 같은 스타일로 확장했다. 공식 로고·상징색 원본과 기존 버튼·탭 팔레트는 변경하지 않았다.

## 변경 범위

`domain/model/HomeGradient.kt`의 홈 전용 목록을 4팀에서 10팀으로 확장했다. 구단 목록 명칭도 previews → all로 정리했다. 기존 `HomeScreen.kt`·`GameApp.kt`의 공통 표시 코드는 그대로 사용한다. 전체 그라데이션, 흰색 메인 카드, 흰색 12% 반투명 안내 카드와 흰색 100% 텍스트를 모든 구단에 적용한다. 기타 화면의 밝은 배경·버튼 강조색·공통 위험색은 유지한다.

`HomeGradientTest.kt`는 10개 구단의 누락·중복, 기존 4팀의 최종 색상과 알파 보존, 그라데이션 256지점의 원배경 및 실제 합성식 배경 대비를 검증한다. 저장된 응원팀을 기준으로 테마를 변경하는 로직, 임시 팀과 편집 초안의 분리, 인증·재생·알림 판정·행동 이벤트 기록기는 수정하지 않았다.

## 실기기·갤러리

Samsung SM-N960N, Android 10/API29, USB device. 분리된 QA 앱만 데이터 초기화 없이 업데이트했다. UI에서 응원팀을 저장한 뒤 각 구단의 기본 1.0·1.3배 홈을 촬영했다. 최종 갤러리는 기본·확대 20개 원본과 10팀 개요 이미지를 포함한다. 확대 화면에서도 팀 이름·카드 본문이 잘리지 않으며 스크롤로 하단에 접근할 수 있다.

이전에 승인한 네 팀의 기본·확대 8개 화면을 이전 실기기 PNG와 비교했다. 시간·알림 상태 표시를 제외한 앱 영역 `(0,70)-(1080,2080)`의 픽셀이 모두 동일하다. [보존 비교 결과](home-gradients-preserved-four.json).

각 스크린샷에서 안내 카드 내부 빈 여백 x70의 제목~본문 높이 구간을 매 행 샘플링하고, 같은 높이 카드 바깥 x20의 배경과 흰색 12% 합성식을 대조한다. 흰색 텍스트와 실제 합성 배경의 대비가 모두 4.5:1 이상인지 확인한다. [실제 렌더 대비 측정](home-gradients-final-device-contrast.json). 이는 스크린샷 sRGB의 상대휘도 계산이며 물리 디스플레이 밝기를 광학 측정한 결과나 안티앨리어싱 가장자리 픽셀 측정은 아니다.

검증 후 QA의 원래 LG·알림 14/16·qa@example.com 및 시스템 font_scale 0.8 복구를 UI·ADB로 확인했다. 일반 앱 설정 해시는 기존과 동일한 c6d450368d1d02a847beea6f0213667790fbd5bf512779d6b7068bf604783ae4다. 제공 SVG·PNG 13개 해시도 모두 동일하다.

[실제 로그](home-gradients-device-log.txt)의 PID 30428에서 새 프로세스 app_open 1건·세션 복원 성공을 확인했다. 팀 변경 저장만 한 이번 흐름에서는 first_done·repeat_done·drop이 모두 0건이었다. 알림 열람·설정 재저장·미저장 토글 이탈의 전체 행동 흐름은 이번 실기기 검사에서 다시 수행하지 않았으며 기존 단위 테스트로 회귀 확인했다.

## 빌드·회귀

| 구성 | 명령 | 결과 |

| 일반·릴리스 | `.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:assembleRelease :app:testReleaseUnitTest` | 성공 33초, 디버그·릴리스 각각 133개 실패·오류 0 |

테스트는 실제 실행됐다. 기존 132개에 승인한 네 팀 색상·알파 보존 테스트 1개를 추가했고, 기존 대비 테스트를 10팀으로 확장했다. 기존 비즈니스 회귀 테스트를 포함한다. 메모리 제한 옵션은 `-Dorg.gradle.jvmargs=-Xmx1536m -XX:MaxMetaspaceSize=512m`, `--max-workers=1`. 설치 QA APK는 `build/handoff/ClutchAlarm-HomeGradients-QA.apk`.

실기기는 홈·응원팀 저장·복구 중심이며 이번에 인증·경기 전체·시스템 알림 흐름을 다시 실행하지 않았다. 행동 이벤트 기록 기준은 수정하지 않았다. 다른 Android 버전·기기·밝기·TalkBack은 미검증이다. 기존 작업 트리를 보존했고 커밋은 생성하지 않았다.
