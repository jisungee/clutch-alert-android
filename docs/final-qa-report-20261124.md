## 4. Android12/13 이상 기능 — API36 에뮬레이터에서 통과

### 시스템 스플래시

기본 애니메이션 값1, 프로세스 소멸 확인 후 실제 런처 아이콘을 눌러 실행했다. 네이티브 원형 설치 아이콘 → Compose 서비스 로고/로그인 확인 화면 → 로그인 화면을 프레임으로 촬영했다. 아이콘·문구가 잘리는 문제는 관찰하지 않았다. 자동화 가속용 애니메이션0/직접 am start의 초기 프레임은 이 스플래시 판정 증거에서 제외했다.

## 6. 발견 사항·인계 판단

**수정이 필요한 앱 결함은 발견하지 않았으며 앱 코드를 수정하지 않았다.** 초기 자동화 2회는 재생 중 이동한 버튼/그룹 요약 좌표를 잘못 선택해 개별2번 열람 증거를 만들지 못했으므로 통과 결과에서 제외했다. 개별 알림을 분리해 탭하고 POST_ID/NEW 로그를 대조하는 방식으로 신규 설치 상태를 재실행했다. 위 PID8420은 요청 순서를 만족한 유효 실행이며 이전 PID3450/6783 이벤트와 합산하지 않았다. 이는 자동화 절차 수정이며 알림·인증·이벤트 코드 수정이 아니다.

남은 범위:

- 실제 인증/세션 갱신/로그아웃 폐기/서버 삭제, 이벤트 API·event_id·영속 outbox·재시도·서버 중복 집계·오프라인 복구는 미연결. 서버 담당자가 연결해야 한다.
- API31/33 정확 버전·다른 제조사·TalkBack, 디스크 부족/Keystore 실패·네트워크/서버 오류의 실기기 주입은 미검증. 오류 분기는 단위 테스트와 구현 경계를 참고한다.
- 이번 실행에서 동일ID 재전달·회전·2번→1번 역순을 별도로 다시 실행하지 않았다. 최신 전체 단위 테스트 및 기존 실기기 증거와 구분한다.
- 이번 테마 유지 검사는 에뮬레이터 한화/삼성과 업데이트 실기기 키움이다. 10팀 기본/1.3배 전체 디자인 증거는 [이전 최종 홈 보고서](home-gradients-final.md)이며 이번에 재촬영했다고 주장하지 않는다.
- 실제 운영 배포는 서버 연결·서명·스토어 업데이트·버전 이관 QA가 추가로 필요하다. 확정 커밋의 별도 체크아웃 재현 빌드 결과는 최종 버전 검증 영수증으로 별도 기록한다.

이 미연결·미검증 범위를 인계 문서에 함께 명시하면 **클라이언트 소스/QA APK의 서버 담당자 인계를 막는 새 결함은 없다.** 최종 커밋·원격 동기화는 이 현장 QA 기록 이후의 버전 확정 절차로 진행한다.

## 증거 파일

Git에는 위 로그·집계 JSON·이 보고서만 포함한다. 원본 스크린샷과 갤러리는 별도 시각화 폴더 `final-qa/report.html`에 보관한다. 기기 데이터 백업·에뮬레이터 userdata·APK·빌드 캐시는 Git/소스 인계에서 제외한다. 검증 후 이번에 만든 FinalQA 에뮬레이터만 종료했으며 기존 AVD·실기기 설치와 설정은 유지했다. 전달 경로 목록은 증거 파일을 포함해 `docs/handoff-files.txt` 211개로 재생성했다. 초기 실패 시도·런처 배경화면 프레임은 갤러리에서 제외한다.
