# 실제 경기 기반 재현 10경기 통합 검증

> 10경기 최초 연결 단계의 기록입니다. 현재는 합성 8개가 모든 앱에서 제거되고 테스트 전용으로 이동했습니다. [최신 홈 바로가기 검증](home-shortcut-validation.md)을 참고하세요.

기준일 2026-11-24. 기존 확정 커밋 d6204eb 이후의 미커밋 작업이다. 커밋·푸시는 수행하지 않았다. 이전 MVP-20261127 APK/영수증과 이번 변경판을 혼동하지 않는다.

## 구현 결과

- 일반 디버그·모든 릴리스는 실제 경기 기반 재현 10개/374개 이벤트만 목록과 APK에 포함한다.
- 기존 합성 8개 파일은 내용을 보존해 `app/src/behaviorQa/assets/games/`로 이동했다. QA 디버그(`-PbehaviorQa=true`)에서만 해당 assets 경로와 qa-catalog.json을 포함한다. QA 목록은 추천/전체 실제 경기 10개/합성 8개를 구분한다. 일반·릴리스는 QA 카탈로그를 읽지 않으며 APK에도 합성 JSON이 없다.
- 제공된 실제 경기 원본 10개는 변경 없이 `app/src/main/assets/games/`에 복사했다. [원본 SHA-256](ten-game-source-hashes.json) 및 APK 내부 파일까지 원본과 대조했다. 기존 합성 8개도 HEAD의 내용과 동일함을 확인했다.
- 저장된 응원팀의 preparedForTeamId와 일치하는 전용 경기를 우선 추천한다. 전체 경기 10개는 별도 섹션에서 모두 열 수 있다. 추천은 단순 참가 팀 매칭이 아니라 각 파일이 준비된 대상 구단을 기준으로 한다. 응원팀을 바꾸면 저장된 설정을 통해 추천이 다시 계산된다.
- 날짜, 원정/홈 구단 로고와 이름, 누적 delay_sec에 따른 1배속 예상 시간을 표시한다. 목록에 점수/승자/끝내기 등의 결과를 표시하지 않는다. 상세 초기 상태도 0:0이며 최종 점수는 재생 결과로만 나타난다.
- 응원팀 참가 경기는 기존 ViewModel의 저장된 preferredTeamId를 사용해 별도 임시 팀 선택 없이 재생한다. 다른 경기의 임시 팀 선택은 저장 응원팀과 전역 테마를 변경하지 않는다.
- 변환은 기존 SelectedPlayGameAdapter를 10경기 모두에 재사용한다. 미상 B/S/O·주자·선수·시각, 이닝 잔여 득점, 관측된 뒤처짐 이력·역전, 구조화되지 않은 판독/끝내기 처리 기준을 유지했다.
- NotificationSession의 중복 방지, 한 레코드 최대 1건, 16개 구독 및 행동 이벤트 발생 코드는 보존했다. source sub_types를 추가 알림으로 직접 발송하지 않는다.

## 실기기 확인 범위

Samsung SM-N960N, Android10/API29, adb device. 기존 QA 패키지를 업데이트 설치했으며 계정·세션·응원팀·알림 설정을 삭제하거나 재저장하지 않았다. 자동 로그인된 기존 설치에서 키움 추천→상세 자동 팀 선택→10x 완주를 확인하고 나머지 9경기도 각각 열어 10x 완주했다. 10경기 모두 최종 점수/완료 상태와 발송 이력 건수가 위 표와 일치한다. 추천·전체 목록의 날짜/로고/이름/재생 시간과 결과 비노출, 뒤로 가기, 키움 전역 테마·저장 응원팀 유지를 확인했다.

PID22630의 발송 성공 로그 352건, 설치 순번69~420 연속, 순번과 발송 ID 중복 없음. 같은 프로세스의 행동 로그는 app_open1건이며 first_done/repeat_done/drop0건이다. 목록 직접 진입과 재생만으로 알림 열람/설정 이벤트가 추가되지 않았다. 신규 설정 저장/실제 알림 탭 흐름을 이번 실기기 세션에서 재실행한 것은 아니며 해당 기준은 기존 전체 회귀 테스트로 확인했다.

각 경기 완료 화면과 발송 이력 화면 20장, 추천 목록/홈 2장 총22장을 별도 시각화 폴더 `ten-game-qa/gallery.html`에 보관했다. 팝업 알림이 일부 완료 화면 상단에 실제로 표시되어 있으나 점수와 완료 상태는 확인할 수 있다. 352개 본문을 모두 수동으로 펼쳐 대조한 것은 아니며 전체 ID/본문은 JVM, 시스템 발송은 프로세스 로그 및 경기별 화면 이력을 대조했다.

QA 자동 탐색 초기에는 긴 스크롤로 한화 카드를 건너뛰고 카드의 홈 표기를 홈 탭으로 오인했다. 탐색 간격과 하단 탭 선택을 수정한 뒤 해당 경기를 정상 실행했다. 실패 시도는 완료 결과에 포함하지 않았고 잘못 연 합성 경기를 재생하지 않았다. 앱 수정이 필요한 문제는 아니었다.
