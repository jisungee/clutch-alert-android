# 홈 그라데이션 4구단 미리보기

2026-11-24. 사용자가 지정한 이전 홈 스크린샷의 전체 그라데이션·흰색 메인 카드·흰색 반투명 안내 카드를 복원한다. 우선 한화·삼성·KIA·KT에만 적용했다. 다른 6개 구단은 승인된 밝은 중립 홈을 유지하며 디자인 확인 후 별도 적용한다.

## 범위

- `domain/model/HomeGradient.kt`: 홈 전용 색상·반투명 안내 카드 알파·대비 보정. 기존 TeamBrand의 공식 원색과 버튼 팔레트는 변경하지 않았다.
- `ui/HomeScreen.kt`: 해당 네 구단에만 그라데이션, 흰색 100% 텍스트, 흰색 12% 반투명 안내 카드 적용. 흰색 메인 카드와 최신 로고·글자 크기·여백·안내 문구·스크롤은 유지했다.
- `ui/GameApp.kt`: 네 구단 홈의 상단 바를 그라데이션 상단과 같은 색으로 연결하고 제목·액션·시스템 상태 아이콘은 밝게 표시한다. 마이페이지·설정·상세·인증 화면 팔레트는 유지했다.
- 저장된 응원팀만 전역 테마와 홈 배경을 결정한다. 편집 초안·경기 임시 팀 및 인증·설정 저장·알림·재생·행동 이벤트 로직은 변경하지 않았다.

## 실제 렌더링 검증

Samsung SM-N960N / Android 10 / USB device. 일반 앱과 분리된 기존 QA 앱을 데이터 초기화 없이 업데이트했다. 저장된 팀을 UI에서 네 차례 바꿔 기본 1.0·확대 1.3의 총 8개 홈을 촬영했다. 전체 배경·공식 로고·흰 카드·반투명 안내 카드·밝은 텍스트·하단 탭을 시각 확인했다. 확대 상태에서 팀 이름과 본문이 잘리지 않고 아래 영역은 스크롤할 수 있다.

스크린샷의 안내 카드 내부 빈 여백(x70)을 제목부터 본문 하단까지 매 행 샘플링하고, 같은 높이 카드 외부(x20)의 배경과 비교했다. 실제 색상이 흰색 12% 합성식과 채널당 오차 0.84/255 이내로 일치했다. 샘플 배경과 흰 글자 색으로 WCAG 상대휘도 대비를 계산했다. 디스플레이를 광학 측정한 결과나 안티앨리어싱 가장자리 글자 픽셀을 기준으로 한 결과는 아니다.

| 구단 | 기본 실제 안내 카드 최소 대비 | 1.3배 실제 안내 카드 최소 대비 |
|---|---|---|
| 한화 | 5.534:1 | 5.565:1 |
| 삼성 | 7.036:1 | 7.146:1 |
| KIA | 6.079:1 | 6.122:1 |
| KT | 9.894:1 | 10.050:1 |

[실제 합성 배경 측정값](home-gradient-device-contrast.json). 보수적인 단위 테스트는 안내 카드가 향후 위로 이동하더라도 4.5:1을 충족하도록 보호한다.

검증 후 QA의 원래 LG·알림 14/16·기존 계정과 시스템 font_scale 0.8을 복구했다. LG 홈이 기존 밝은 중립 스타일임을 별도로 촬영했다. 일반 사용자 앱은 변경하지 않았다.
